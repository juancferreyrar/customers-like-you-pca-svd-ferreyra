# customers-like-you-pca-svd-ferreyra
PCA and SVD retail recommendation mini-project

J1: Success Targets
The overall goal of the project is to ensure that the size of the customer-product matrix is reduces through Truncated SVD, ensuring that the reccommendations remain useful. The main goals are to reduce the storage size by around 80%, and ensuring that the recommendation job can be fulfilled in under 60 seconds while being reproducible. We want to identify different customer groups through purchasing behavior and describe them through common products and countries.

Running Instructions:

As the data is not included in this repository, please go to the following website to access the original dataset:
https://archive.ics.uci.edu/dataset/502/online+retail+ii

Once downloaded, please extract to Google Drive and save it in a "data/raw/ folder". If any problem appears, please change the directory or ensure that the path has been succesfully copied. Google Colab might require permission to access to your Google Drive.

Once the data is loaded successfully, you can run the notebook cells from top to bottom.
